# Task: 1.0 Refactorize
I'd like to refactor the codebase to improve maintainability, readability, and performance. 

Specifically, I want to promote the CLI REPL to a first-class interface, and treat the `hepagent run` command as end-to-end task-oriented interface. The CLI REPL should be used for interactive exploration and debugging, while the `hepagent run` command should be used for executing tasks in a more automated manner. 

Users will use `hepagent repl` for day-to-day workflows: describe a new task, interacte with the agent to finish the task, and document the progress and findings to the LOGBOOK.md or the tasks/task.md files. These documents will improve Agent's knowledge and capabilities over time.

The main usage of the `hepagent run` is to evaluate the `hepagent` under the terminal bench. See the terminal bench documentation for detail: https://www.harborframework.com/docs/agents. No textual TUI is needed.
