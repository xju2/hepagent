The JFC repository in the folder `testarea/jfc`contains the source code and harnesses for orchstrating Claude Code
to autonomously perform physics analysis from reading data to writing papers.
Read the respoitory carefully and understand the code and harnesses.

Use high-level reasoning to extract the workflow of the analysis process
and how HepAgent can implement it in a programmable way.
The core idea is to use HepAgent to orchestrate the workflow of the analysis process
using OpenAI Agent SDK instead of relying on the Claude Code harnesses.


Before writing any code, first write the tasks in the `tasks/jfc` directory that needs to be done to
implement the analysis workflow using HepAgent.
The tasks should be written in a clear and concise manner, and should be actionable.
The tasks should also be prioritized based on their importance and dependencies.
