# Task 2.0: Make the new skill reachable for existing homes

Adding the Fundra skill only under the repo `.agents` tree means it is invisible for users who have already run HepAgent once: get_agent_dir() prefers `~/.hepagent/agents` whenever it exists, and bootstrap_hepagent_home() copies repo defaults only when that directory is missing. In that common existing-user case the skill catalog and load_skill_details("fundra-workflows") will still read the old user registry and report this new skill as absent unless the user manually deletes or copies files, so the feature needs a merge/fallback path for newly bundled skills.

## Progress report

- Completed: `bootstrap_hepagent_home()` now copies missing bundled skill directories into an existing user registry without overwriting existing user skills. Added a regression test covering an old user registry gaining `fundra-workflows`.
