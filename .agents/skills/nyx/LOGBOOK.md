- **Corrective Insight:** Nyx simulation crashed with illegal memory access in heating/cooling module because gas density was zero. This happened because do_hydro=1 but the initial conditions from cosmicic only provided particles and do_santa_barbara was set to 0. | **Correction:** When running Nyx with do_hydro=1 and using only particle initial conditions (PrintFormat=5 or similar without gas), set nyx.do_santa_barbara=1 and nyx.init_sb_vels=1 to initialize gas from the particle distribution. Otherwise, gas density will be zero, leading to illegal memory access in the heating/cooling module.
